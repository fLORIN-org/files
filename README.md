# 🤖 Telegram-бот для колледжа

Простой бот для просмотра расписания и домашних заданий.

---

## 📦 Установка

### 1. Получить токен бота
1. Написать [@BotFather](https://t.me/BotFather) в Telegram
2. Отправить команду `/newbot`
3. Придумать имя и username для бота
4. Скопировать полученный токен

### 2. Вставить токен в код
Открыть `bot.py` и заменить строку:
```python
TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"
```
На ваш реальный токен, например:
```python
TOKEN = "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
```

### 3. Установить зависимости
```bash
pip install -r requirements.txt
```

### 4. Запустить бота
```bash
python bot.py
```

## ⚙️ Как это работает

### База данных (SQLite)
Создаётся автоматически при первом запуске. Содержит 4 таблицы:
- `users` — зарегистрированные студенты
- `schedule` — расписание занятий
- `homework` — домашние задания
- `notifications` — лог уведомлений

### Тестовые данные
При первом запуске автоматически добавляется расписание для групп **ИТ-11** и **ИТ-12**
и несколько домашних заданий. Можно протестировать сразу.

## ➕ Как добавить своё расписание

В функции `fill_test_data()` в файле `bot.py` есть список `test_schedule`.
Каждая строка — это одна пара:

```python
("ГРУППА", ДЕНЬ_НЕДЕЛИ, НОМЕР_ПАРЫ, "ПРЕДМЕТ", "ПРЕПОДАВАТЕЛЬ", "АУДИТОРИЯ")
```

Дни недели: `0` = Пн, `1` = Вт, `2` = Ср, `3` = Чт, `4` = Пт, `5` = Сб

Пример:
```python
("ИТ-11", 0, 1, "Математика", "Иванов А.П.", "101"),
```

> ⚠️ Если база уже создана — удалите файл `college.db` и перезапустите бота, чтобы данные обновились.
